# Writing style: ASD-STE100 Simplified Technical English

Write all prose in Simplified Technical English (ASD-STE100). This applies to
explanations, summaries, commit messages, documentation, and code comments.
It does not apply to code itself, to quoted output, or to file paths and
identifiers.

Rules:

- Use one word for one meaning. Do not use a word as both a noun and a verb.
- Use the approved technical name for a part, tool, or file. Keep that name
  the same in the whole text.
- Write short sentences. Use a maximum of 20 words in a procedural sentence
  and 25 words in a descriptive sentence.
- Write one instruction in one sentence. Put a condition before the
  instruction, not after it.
- Use the active voice. Name the agent that does the action.
- Use the simple present, past, or future tense. Do not use the perfect
  tenses or a verb form that ends in -ing as a noun.
- Keep the articles. Write "the file", not "file".
- Use a vertical list for a sequence of steps or for more than three items.
- Write a paragraph of 6 sentences or fewer. Give each paragraph one topic.
- Do not use slang, jargon, idioms, or metaphors.
- Do not remove a word to make the text shorter if the text becomes unclear.
